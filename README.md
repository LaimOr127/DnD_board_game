# Море имён

Самостоятельное средневековое приключение 16+ для стола с двумя шестигранниками. Для игры начните с «Море имён/00 Первый вечер.pdf». Полный каталог игровых материалов — «Море имён/Начать здесь.txt».

## Общий игровой стол

**[Открыть «Море имён»](https://more-imen-table.sweetgoldfish9.chatgpt.site)**

В браузере нажмите **«Создать стол»**, введите имя и выберите одного из 18 героев. В меню **«Пригласить друзей»** есть ссылка и код. У каждого участника свой лист. Создатель может взять героя либо вести только общее поле. При игре вдвоём достаточно выбрать по одному герою. Когда все рассядутся, раздайте стартовое серебро и прочтите «Нулевой удар». Решение о ленте или ложке запустит первую сцену на переправе.

Кидайте два обычных d6 или нажимайте «Бросок кубиков». В режиме «Внести физические кости» сайт запишет грани, сам посчитает модификаторы и покажет результат всем. Для преимущества и помехи нужны три результата d6, для дороги и оракула — один. Настоящие миниатюры можно передвигать по напечатанным зонам и отмечать те же шаги на карте. Эффекты особых карт обсуждают за столом. Фактическое здоровье и снаряжение вносят на листы.

Для 3D-принтера есть [береговой d6, 16 мм](<Кубики/Береговой d6 — 16 мм.stl>). Напечатайте две копии, при желании третью другого цвета. На противоположных гранях в сумме семь точек. Глубина точек 0,6 мм, их диаметр подобран так, чтобы с каждой стороны убрать одинаковый объём пластика. Геометрия проверена цифровым способом. Равномерность физического кубика зависит в том числе от печати. Пример броска первой ступени — выпало 3 и 5, у героя Ловкость 2. Итог 10 проходит порог 9.

В книге правил внутри сайта есть поиск и печатный PDF. Раздел «Ведущий» показывает реплику всей группе. Кнопка озвучивания читает её голосом устройства. Видеосвязь для партии не требуется.

### Из разных мест

В размещённой версии оставьте вкладку создателя открытой. Продолжение сохраняется в этом браузере. После перезагрузки откройте сайт в том же профиле. Для соединения нужен интернет и сеть с поддержкой WebRTC. Для сценария и правил ключи не требуются. Создатель может включить русскоязычного ИИ в меню ведущего на устройстве с поддержкой WebGPU. Браузер заранее покажет размер загрузки. Рассказы ИИ остаются в журнале, а изменение сцены и броски подтверждают игроки.

### За одним Wi-Fi

На компьютере с Python 3.10 или новее запустите **«Игровой стол.cmd»** двойным щелчком. Также можно выполнить из корня проекта `python site/server.py --bind 0.0.0.0 --open`. Сервер напечатает адреса для телефонов в домашней сети. Игровые материалы, карты и правила доступны без интернета. Сохранения лежат в `site/data/rooms.sqlite3`. Для возврата к личному месту нужны тот же адрес сервера и тот же профиль браузера.

Для генеративного ведущего локальный сервер поддерживает установленную модель Ollama по имени из переменной окружения `OLLAMA_MODEL` (локальный адрес 127.0.0.1:11434), либо OpenAI Responses API с серверными `OPENAI_API_KEY` и при необходимости `OPENAI_MODEL`. Ollama имеет приоритет, если заданы оба варианта. В облачный API при таком выборе передаются вопрос, текущая сцена и последние записи журнала. Без модели доступен сценарный сказитель.

### Проверка и сборка сайта

Запустите `python site/test_table.py`, `python site/test_story.py` и `python site/test_server.py`. Статическую версию для HTTPS-хостинга собирает `python site/build_hosted.py` в `site/dist`. При первой сборке нужны сеть и доступ к закреплённым версиям зависимостей. Печатные материалы уже входят в репозиторий.

Готовый комплект собран в папке «Море имён». Исходники: design/rules.md и build/*.py. Данные мира, героев, предметов, врагов и политических веток хранятся отдельно от отрисовки, так что изменение текста проходит в PDF и карточки из одного источника. Иллюстрации и миниатюры оригинальные, построены из рисунков и геометрии этого проекта. Референсы в поставку не копируются.

## Пересборка на Windows

Нужен Python 3.13, зависимости из requirements.txt и шрифты Arial, Georgia из C:/Windows/Fonts. Из корня запустить в таком порядке:

1. python build/table.py — книги, карты, карточки PNG, исходный каталог.
2. python build/models.py — рельефы, предметы, поселения и аксессуары.
3. python build/miniatures.py — полные объёмные наборы H/M/B и общий реестр габаритов.
4. python build/workshop.py — иллюстрированная мастерская и карта угроз.
5. python build/verify.py — независимая проверка экспорта и моделирование.
6. python build/package.py — архив, сверка распаковки и локальный предпросмотр.

Инструменты разработки и временные растры не входят в игровой архив. Физических испытаний принтера и плейтеста не было.
