# Ориентиры для фигур и декораций «Моря имён»

Объёмные фигуры высотой до 50 мм вместе с основанием. Для героя важны лицо, одежда, осанка и предмет из его истории. Для существа важны анатомия, движение и читаемый силуэт. У босса знакомый по сцене предмет должен быть виден сбоку, когда фигурка стоит на поле. Код на основании нужен для сверки с карточкой.
